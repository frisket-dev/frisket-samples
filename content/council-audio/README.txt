ANN ARBOR COUNCIL AUDIO LAB

This package contains two five-minute excerpts from public meetings recorded by
Michelle Ryan Hughes and published by the copyright holder under CC0 1.0 on
Wikimedia Commons. The excerpts were converted from Ogg Vorbis to mono 16 kHz,
48 kbps MP3 files. See manifest.csv for source URLs, checksums, dates, and exact
clip boundaries.

TRY THIS IN FRISKET

1. Upload both MP3 files together as a Files import.
2. Open Document view and play a source clip.
3. Run Transcribe on the media column and save the result as transcript.
4. Compare the transcript with the audio around names, numbers, and crosstalk.
5. Extract speakers, organizations, agenda topics, commitments, and dates.
6. Summarize each excerpt and ask which statements require follow-up.
7. Use Find topic sections to locate changes in discussion.
